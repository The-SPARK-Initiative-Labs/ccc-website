# Custom Computer Connection website

Static site for Custom Computer Connection (PC repair and custom builds, La Grange, Texas), served by GitHub Pages at https://customcomputerconnection.com.

- `assets/css/style.css`: the S.P.A.R.K. terminal theme, copied unmodified from sparklabs-website. Don't edit it here.
- `assets/css/ccc.css`: CCC-specific styles layered on top.
- `index.html`: the main page. `portal.html`: customer login placeholder (not built yet).
- The contact form posts to FormSubmit (formsubmit.co/ajax/ccc@sparkinitiative.io); no account or key. FormSubmit emails an activation link to ccc@ on first use.

Source of truth on Glass: `C:\Business\Custom Computer Connection\Website\ccc-site\`.
